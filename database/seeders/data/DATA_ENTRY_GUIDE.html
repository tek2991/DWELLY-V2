📋 Dwelly Property Onboarding

Standard Operating Procedure & Data Entry Guide

Dwelly Operations Team
Excel / CSV Reference

This guide explains step-by-step how to enter existing properties, owners, signing authorities, tenants, agreements, and photos into the Dwelly system using Microsoft Excel or Google Sheets.

🔑 The Golden Key: Every property is identified by a unique Property Code (e.g. GAU-0091 or BLR-0015). This single code connects the properties spreadsheet, the tenants spreadsheet, the specifications checklist, and the photo folder together.
File 1

Properties CSV

existing_properties_template.csv
Owner info, commercials, rent-share flag, and signing authority.

File 2

Tenants CSV

existing_tenants_template.csv
Primary & secondary co-tenants, Aadhaar, PAN, and tenancy terms.

File 3

Checklist CSV

property_specifications_template.csv
Granular room counts, amenities (yes/no), and appliance counts.

Part 4

Assets Folder

Folder: {property_code}/
Drop mou.pdf, poa.pdf, tenancy.pdf, and images in photos/.

⚡ Quick Start 4-Step Checklist:
  1. Open CSVs: Open existing_properties_template.csv, existing_tenants_template.csv, and property_specifications_template.csv. Keep headers unchanged.
  2. Fill Property & Owner: Fill in one row per property in File 1. Mark is_rent_sharing (true/false) and is_signatory_different (true/false).
  3. Add Occupants in File 2: For occupied properties, enter primary and co-tenants linked by the matching property_code.
  4. Organize Photos & Save: Place scans in storage/app/seed_assets/properties/{property_code}/ and save all files as CSV UTF-8 (*.csv).

🚫 Top 8 Common Mistakes to Avoid

# ❌ What NOT to do ✅ What to do instead
1 Do not write currency symbols or commas
❌ ₹25,000 or 25,000		 Type plain numeric digits only:
✅ 25000
2 Do not add country codes or spaces in phone numbers
❌ +91-98765-43210 or 98765 43210		 Type 10 continuous numeric digits:
✅ 9876543210
3 Do not use DD/MM/YYYY for dates
❌ 15/01/2026 or 15-Jan-2026		 Always use Year-Month-Day format:
✅ 2026-01-15
4 Do not add rows in Tenants CSV for Vacant properties
❌ Adding "N/A" or past tenants		 Leave vacant properties out of the tenants CSV completely.
✅ No tenant rows for vacant properties
5 Do not invent custom city names
❌ "Guwahati City" or "Bengaluru"		 Use standard registered branch cities:
✅ "Guwahati" or "Bangalore"
6 Do not delete or rename CSV column headers
❌ Renaming "rent_amount" to "Monthly Rent"		 Keep Row 1 exactly as provided in the template.
✅ Unchanged header row
7 Do not hardcode agreement or MOU numbers
❌ Trying to enter custom MOU codes		 Dwelly automatically generates sequential MOU-* and TNC-* numbers.
✅ System generated codes
8 Do not save as .xlsx (Excel Workbook)
❌ "properties.xlsx"		 Save as CSV UTF-8 (Comma delimited) (*.csv).
✅ "properties.csv"

❓ Frequently Asked Questions (FAQ)

Q: What is the difference between is_rent_sharing = true and false?
A: true activates the Rent share model where Dwelly deducts a monthly management fee % (e.g. 8%). false activates the Annual subscription model with 0% fee on rent.
Q: How do secondary / co-tenants work?
A: In existing_tenants_template.csv, add another row with the same property_code, setting is_primary_tenant = false and specifying their relationship (e.g. Spouse, Son).
Q: What if I don't have the signed MOU, POA, or tenancy agreement PDF right now?
A: That is completely fine! The system automatically generates a clean digital placeholder so previews work immediately. Real scans can be uploaded later through the Dwelly admin dashboard.
Q: How do I choose which photo appears first on the website?
A: Prefix the image filenames with numbers in the photos/ folder: 01_elevation.jpg will automatically become the featured cover photo.
Q: Can I use 1 and 0 instead of yes and no for amenities?
A: Yes! Both yes/no and 1/0 work interchangeably.
Q: Who do I contact if the system reports an error during import?
A: Ask the tech team to run the dry-run check (--dry-run). The system will pinpoint the exact row number and column name needing correction.
